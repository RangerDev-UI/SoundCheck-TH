Go-Live & Backend Kit (ชุดโค้ดฐานข้อมูล & ขึ้นโฮสต์ฟรี)

คัดลอกโค้ดไปวางใน Supabase / Google Sheets และนำไฟล์ขึ้นออนไลน์ได้ทันที

1. Netlify Drop (เร็วสุด 1 นาที) แนะนำ
  1. กดปุ่ม "ดาวน์โหลดไฟล์ index.html" ด้านบน แล้วนำใส่ในโฟลเดอร์เปล่า 1 โฟลเดอร์
  2. เปิดเว็บ app.netlify.com/drop
  3. ลากโฟลเดอร์ไปวาง ระบบจะสร้างลิงก์ .netlify.app พร้อม SSL ฟรีทันที
2. Vercel (Auto-Deploy) Pro
  1. อัปโหลดไฟล์ index.html ขึ้น GitHub Repository
  2. ล็อกอิน vercel.com แล้วกด Add New Project เลือก Repo ดังกล่าว
  3. กด Deploy ได้ลิงก์ .vercel.app และผูกโดเมนส่วนตัว (.com / .in.th) ได้ฟรี
3. GitHub Pages & แชร์โซเชียล ฟรีถาวร
  1. อัปโหลด index.html เข้า Repo สาธารณะ แล้วเปิด Settings > Pages > Branch: main
  2. เปลี่ยนลิงก์รูปปก og:image ในโค้ดเป็นแบนเนอร์ขนาด 1200x630px ของคุณ
  3. เช็คภาพตัวอย่างก่อนแชร์ที่ Facebook Sharing Debugger หรือ LINE Page Poker

⚡ Supabase SQL Schema (ตาราง headphones & price_deals)
